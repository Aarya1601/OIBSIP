# Sales Prediction Using Python

## Data Science Internship – Oasis Infobyte

This project predicts product sales based on advertising expenditure across TV, Radio, and Newspaper channels.

## Models Used

- Linear Regression
- Random Forest Regressor

## Evaluation Metrics

- MAE
- RMSE
- R² Score

## Best Model

Random Forest Regressor achieved the best performance with an R² score of 0.981.

## Feature Importance

- TV: 0.6248
- Radio: 0.3622
- Newspaper: 0.0130

TV advertising was the most important feature for predicting sales.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab
