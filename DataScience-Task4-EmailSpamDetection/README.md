# Email Spam Detection Using Machine Learning

## Data Science Internship – Oasis Infobyte

This project uses Natural Language Processing (NLP) and machine learning to classify messages as spam or ham.

## Models Used

- Multinomial Naive Bayes
- Logistic Regression

## Text Processing

- Lowercase conversion
- Punctuation removal
- Stopword removal
- TF-IDF feature extraction

## Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

## Best Model

Multinomial Naive Bayes achieved the best performance with:

- Accuracy: 96.23%
- Precision: 100.00%
- Recall: 71.81%
- F1-score: 83.59%

Based on these results, Multinomial Naive Bayes was selected as the best-performing model.

## Bonus

WordCloud visualizations were created for both spam and ham messages.
